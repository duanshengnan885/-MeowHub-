# Live2D 桌面宠物模型目录

这里是存放星喵 Live2D 模型文件的目录。

### 如何替换为你自己的模型？

1. 使用 Live2D Cubism 导出你的模型，确保导出格式包含 `.moc3` 和 `.model3.json`。
2. 将所有导出的文件（包括纹理文件夹、物理文件等）全部放入这个文件夹 (`assets/live2d_pet/`) 中。
3. **重要：请确保你的模型主配置文件名被重命名为 `model.model3.json`**，因为代码默认会加载这个名称的文件。
4. 如果你放入了正确的 `model.model3.json`，系统会自动隐藏 `placeholder.png` 占位图，并加载你真实的 Live2D 宠物。
5. 你可以通过桌面右上角的 `📍 记忆位置` 按钮来保存宠物当前的拖拽坐标。

如果有报错，请在项目根目录按 F12 (需要配置开启 debug) 或者查看 `debug_js.log` 查看日志。
