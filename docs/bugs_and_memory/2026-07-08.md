## 2026-07-08 Bug: 画图模型文件不存在导致 HTTP 400

### 现象
`
[DRAW] Model type detection failed, assuming SD/SDXL: [Errno 2] No such file or directory: 'D:/AI/画图模型/flux1-schnell.safetensors'
...
urllib.error.HTTPError: HTTP Error 400: Bad Request
`
画图功能因 active_model 路径指向已不存在的文件而失败。

### 根因
pp_config.json 中 ctive_model 的值为 D:/AI/画图模型/flux1-schnell.safetensors，该文件及目录 D:\AI\画图模型 均已不存在。_drawing_worker 无对应校验，导致：
1. 模型类型检测崩溃 → 回退 SD 流程
2. ComfyUI 无法加载不存在的 checkpoint → 400

### 修复
在 _drawing_worker 中增加模型文件存在性校验，不存在时返回明确错误并引导用户重新导入。

### 教训
模型路径容错应与 ComfyUI 路径容错一起处理。

### 修复
在 _drawing_worker 的 ckpt_name 解析之后、	ry 检测模型类型之前，插入文件存在性校验：
`python
local_path = drawing_model["id"]
if not os.path.isfile(local_path):
    self._send_error(
        "画图模型文件不存在: " + os.path.basename(local_path)
        + "\\n请点击「🎨 一键导入画图模型」重新导入模型目录"
    )
    return
`
文件不存在时返回明确错误并引导用户重新导入，不再继续发送无效 workflow 导致 HTTP 400。

### 验证
pi.py 语法通过。改动文件：pi.py 1 处。
