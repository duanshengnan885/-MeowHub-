# 2026-08-03 Bug 记录

## 1. README 依赖包名错误
- **现象**：照抄 README 中的 `pip install` 会报错或装错包。
- **根因**：使用了 `webview` 作为包名，但正确在 pip 上的包名应为 `pywebview`；缺少了必要的 `psutil` 依赖，多出了运行期不需要的 `pyinstaller`。
- **修复**：修改 `README.md` 的依赖清单，更新为 `pip install pywebview openai psutil pystray pillow`。
- **教训**：编写文档和脚本的依赖时，包的导入名和 pip 安装包名可能不同，应以实际运行或部署测试使用的名为准，注意检查。

## 2. Windows-only 硬编码路径备份 Bug
- **现象**：项目每次启动时，会在系统生成垃圾文件夹 `F:\MeowHub_Backups`。
- **根因**：`main.py` 入口处写死了强依赖 F 盘路径的自动备份代码，对其它系统和未插 F 盘的用户属于副作用。
- **修复**：将 `main.py` 底部的备份代码移除，并将该功能重构抽取为独立脚本 `scripts/local_backup.py`。备份目录改为动态依赖项目名称 `F:\{项目名}_Backups`。
- **教训**：个人测试用途的硬编码路径切勿直接提交；如果是一些专属的、可能会打扰其他用户的个人维护功能（如自动备份），应该将其抽离为独立的工具脚本，而不是植入到主程序的生命周期中，以免强加给其他用户。
